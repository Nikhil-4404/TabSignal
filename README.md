# TabSignal

Share chosen Chrome and Brave website activity on Discord desktop.

TabSignal uses a browser extension and a small Windows companion. You choose the websites and enable sharing; optional media access adds artwork and playback details.

## Release status

The public release is being prepared. No public companion installer or extension listing is available yet.

This repository is the public download and setup home. Personal development copies and owner-only preview packages are not public releases and are not hosted here.

## Downloads

Tested public packages and their setup instructions will appear on the [Releases page](https://github.com/Nikhil-4404/TabSignal/releases) when available.

## Setup when released

1. Add the TabSignal extension using its official listing.
2. Run the Windows companion installer once.
3. Open TabSignal, choose websites and enable sharing with Discord desktop open.

No separate Node installation, PowerShell commands or manual Discord Application ID will be required.

Use [GitHub Issues](https://github.com/Nikhil-4404/TabSignal/issues) to report problems. Do not include passwords, tokens or private browsing details.
